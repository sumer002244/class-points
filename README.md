# 🏫 班级积分管理系统

> 基于 TeacherLab 班级积分工具的独立部署版本

## 功能一览

| 功能模块 | 说明 |
|---|---|
| 📊 **今日看板** | 当天的班级概况、值日进度、光荣榜 |
| ⭐ **积分点评** | 正/负向行为加减分，支持整组点评 |
| 📝 **考试成绩** | 录入月考成绩，自动排名，折算积分 |
| 🪑 **座位编排** | 拖拽排座，一键随机铺座 |
| 🧹 **值日安排** | 自定义值日项目，每天指定同学 |
| 👥 **小组管理** | 创建小组，整组点评，全组扣分 |
| 🖥️ **大屏展示** | 教室一体机展示模式，自动回锁 |
| 📈 **统计报表** | 雷达图、热力图、光荣榜、成长档案 |
| ⚙️ **系统设置** | 行为库、学期、班级信息、数据管理 |

## 快速启动

```bash
# 方式一：Python
python3 -m http.server 8080

# 方式二：Node.js
npx serve .

# 方式三：直接打开
# 部分浏览器因 file:// 限制无法加载 ES Module，
# 建议用 HTTP 服务器方式
```

## 数据安全

所有数据存储在**浏览器本地**（localStorage），绝不上传至任何服务器。清除浏览器缓存会丢失数据，请定期导出备份。
